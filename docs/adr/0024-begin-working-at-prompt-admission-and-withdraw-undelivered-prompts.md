# Begin Working at Prompt admission and withdraw undelivered Prompts on interrupt

Between a Prompt's admission and its delivery, the server may spend seconds starting a Provider process, and nothing in the Session said so: `working_since` was derived only from Turn intervals, and the Turn, the user Message, and the Working Indicator all appeared together once startup succeeded. We now derive Working from an admitted-but-undelivered Prompt as well as from unsettled Turns and surviving Subagents, so `working_since` may precede any Turn, and every client draws a Pending steer Prompt in the Transcript's position as the user Message it will become. Because such a Session is Working, Escape must mean something there: interrupting a Session that is Working only for an undelivered Prompt cancels that Prompt and abandons Provider startup, leaving the Session standing with no Turn, rather than stopping a Turn that does not exist. The alternative — a client-local indicator on the submitting client only, keeping "Working is a server derivation" strictly about Turns — was rejected because it leaves every other client seeing an idle, empty Session while a Provider starts, and because the same gap exists for follow-up Prompts on an idle Session, where only the server knows a startup is under way. The window before the server has answered a creation request at all stays client-local by necessity; that is the Provisional Session, and it is the only place a Working Indicator is drawn without the server's word.

## Consequences

A Session can be Working with an empty Transcript and no Turn, so surfaces that read the active Turn to explain Working must accept "owed to a Prompt" as a state of its own, and the Working Indicator in that state carries no Turn to attribute elapsed time to beyond the admission moment. Interrupt handling gains a branch that mutates a Prompt instead of a Turn, and a withdrawn initial Prompt leaves a Session whose Title came from a Prompt that was never delivered; that Session is kept rather than deleted so its Execution Directory and any prepared Worktree remain usable. A Prompt cancelled this way returns to the composer of the client that interrupted, not to every viewer.
